# Data attribution

The three fixture files in this directory are unmodified excerpts from:

> Pappalardo, Luca; Massucco, Emanuele (2019). **Soccer match event dataset.** figshare. Collection.
> https://doi.org/10.6084/m9.figshare.c.4415000.v5

Licensed under [**CC BY 4.0**](https://creativecommons.org/licenses/by/4.0/), which permits
redistribution with attribution — this note is that attribution. The underlying event data was
collected by [Wyscout](https://wyscout.com). Mirrored from
[koenvo/wyscout-soccer-match-event-dataset](https://github.com/koenvo/wyscout-soccer-match-event-dataset)
(same license), which reprocesses the original release into one JSON file per match.

| File | Fixture | Competition |
|---|---|---|
| `1694390.json` | France v Romania | UEFA Euro 2016, Group A |
| `1694391.json` | Albania v Switzerland | UEFA Euro 2016, Group A |
| `1694392.json` | Romania v Switzerland | UEFA Euro 2016, Group A |

Selected for a spread of shots, corners, cards and goals — see `docs/wyscout-fixtures.md` for the
exact counts each one produces through the CORE market templates.
